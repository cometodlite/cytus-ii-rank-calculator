# CYTUS II 통합 단위인정 계산기

GitHub Pages 정적 사이트입니다. `index.html`에 CSV 330곡 데이터가 내장되어 있습니다.

## 배포
1. GitHub에서 새 Public 저장소를 만듭니다.
2. 이 폴더의 `index.html`을 저장소 최상위에 업로드하고 Commit합니다.
3. Settings → Pages → Build and deployment → Deploy from a branch를 선택합니다.
4. Branch `main`, Folder `/(root)`를 선택하고 Save합니다.
5. Pages 화면에 표시되는 URL로 접속합니다.

## 주의
- B-DCT는 기존 편성 42등급을 포함합니다.
- DCT는 CSV에서 수록곡을 직접 선택합니다. CSV에는 등급별 시험 편성표가 없습니다.
- DCT 합격선 및 MSTT 계산 규칙은 임시 설정이며 공식 확정 기준이 아닙니다.
- 저장된 성적은 해당 브라우저의 로컬 저장소에 보관됩니다.
