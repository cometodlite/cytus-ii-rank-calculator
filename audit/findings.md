# 확인된 결과와 변경 검토 후보

## 확인 결과

1. v1.3의 범위 228은 B-DCT 168 + DCT 60으로 계산한 값입니다. DCT Standard와 DCT MSTT를 독립 유형으로 나누면 DCT가 120 슬롯이 되어 총 **288 슬롯**입니다.
2. 현재 `index.html`의 데이터에는 B-DCT 곡명 배열 168개와 CSV 카탈로그 330곡이 있습니다. 카탈로그의 플레이 기록은 실제 차트 메타데이터가 아닙니다.
3. 현재 프로젝트에는 DCT Standard/MSTT 등급별 4곡 편성 데이터가 없습니다. 사용자가 계산 화면에서 고르는 임시 곡은 원본 시험 편성표로 간주할 수 없습니다.
4. 앱의 HARD/CHAOS 표시는 등급과 슬롯 번호만으로 만들어집니다. 곡별 실제 난이도를 읽어오는 것이 아닙니다. 따라서 표시 결과가 실제 채보 종류와 일치하는지 전체 슬롯에서 대조해야 합니다.
5. 10개 공개 자료 샘플은 출처 페이지의 표기값을 확인하는 데만 사용했습니다. 이 중 KANATA CRASH는 `β`; Chrome VOX는 카탈로그의 `Chrome V0X`와 철자가 다르고, Fireflies 리믹스는 카탈로그의 `Fireflies`와 다른 곡입니다.

## 우선 확인할 변경 후보

아래는 교체 지시가 아니라, 실제 채보 정보 확보 후 먼저 검토할 **슬롯/구간**입니다.

| 우선순위 | 현행 구간/곡 | 확인된 자료 | 검토 이유 |
|---|---|---|---|
| 1 | B-DCT Standard 7단: Brain Power, Chrome VOX | Brain Power CHAOS 13; Chrome VOX CHAOS 14+ | v1.3의 7단 목표 `8/9/10/10`을 크게 넘습니다. 현행 앱은 이 등급의 네 칸을 CHAOS로 추정하지만, 실제 슬롯 채보는 미확인입니다. 두 곡은 현행 배정을 유지할지, 다른 난이도를 쓸지 검토해야 합니다. |
| 2 | B-DCT Standard 4단 이후 | 문서의 단계별 잠정 목표 | 기존 난이도 급상승을 완화하는 개편 핵심 구간입니다. 슬롯별 차트·레벨 확인 전에는 교체안을 정식 편성으로 확정할 수 없습니다. |
| 3 | B-DCT Standard 1~3단 | 사용자 결정 | 현행 곡 배정 유지가 원칙입니다. 이 문서는 목표 레벨을 새로 부여하지 않았습니다. 실제 채보를 대조해 명백한 오류가 확인될 때만 별도 검토합니다. |
| 4 | DCT Standard, DCT MSTT 각 60슬롯 | 현재 공개 저장소 편성 없음 | 목적에 따라 서로 다른 곡/채보를 선정해야 합니다. 둘은 별도 목록으로 새로 수집하고 동일 채보 중복은 확인 후 금지합니다. MSTT 점수식/합격 판정은 보류합니다. |
| 5 | 현행 유형 간 같은 곡명 34종 | B-DCT 곡명 배열 비교 | 같은 곡의 다른 난이도는 허용이므로 곡명 중복만으로 정책 위반은 아닙니다. 실제 채보 ID를 확인해 동일 채보만 걸러야 합니다. |

## 지금 단계의 판정

- 실제 288개 슬롯 중 **검증 완료 0개**, `PENDING` 288개.
- 이는 참고 가능한 레벨 자료가 전혀 없다는 뜻이 아닙니다. 현행 시험 슬롯을 실제 곡 ID, 채보 종류, 게임 버전, 해금 조건과 연결해 입증할 만큼의 데이터가 아직 없다는 뜻입니다.
- `source_samples.csv`의 표본은 변경 검토 근거입니다. 샘플 출처 하나만으로 실제 편성 슬롯의 `song_id`와 채보를 확정하지 않습니다.
- 다음 단계는 기존 168개 슬롯의 실제 채보 식별을 먼저 하고, 동시에 별도 DCT Standard/MSTT 후보 풀을 조사하는 것입니다. 확정된 교체표는 검토 보고를 마친 뒤에 별도 승인을 받아 반영해야 합니다.
